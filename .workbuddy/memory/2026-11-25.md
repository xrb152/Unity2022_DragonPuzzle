## 修正：击退怪物「轨迹不足，本次没有后退」
- 根因：关卡 prefab（`Assets/Resources/Levels/C1/*.prefab`）里 `segmentDistance: 50`、`moveSpeed: 1`，即 1 个身位要吃掉 50 个 marker（约 1 秒行程）。旧公式要求「整条龙完全铺在轨迹上之后还有余量」才允许后退，命中这个条件往往要等几十秒，所以走了很久仍判定 0。
- 新逻辑：`backwardIndex = Clamp(steps * stepMarkers, 1, markerList.Count - 1)`，只要身后还有一点轨迹就一定退；不足 5 节时按实际距离退，返回真实节数。
- 身体节超出轨迹范围时不再 `continue`（原地不动被拉长），改为沿 `[backwardIndex, lastIndex]` 用 `Mathf.Lerp` 均匀压缩，避免多节叠在同一点。
- 副作用（其实是想要的效果）：退到起点后头停在洞口，后续前进时身体节按 `markerList[i*50-1]` 逐节恢复，看起来就是「缩回洞里再爬出来」。
- 加固：`CheckAndHandleDisableSegments` 在 `isMovingBackward` 时直接 return，防止 DOTween 播放中被剔除身体节；`FixedUpdate` 加 3 秒超时兜底复位 `isMovingBackward`（避免序列被打断后永久卡住不前进）。
- `UIGame.OnRetreatRewarded` 日志区分三种情况：完全无轨迹 / 退了几节（不足请求）/ 退满。

## 修正：击退后身体节重叠（挤成一坨）
- 现象：看广告击退后，龙身多节在轨迹上叠成 2~3 排「鳞片墙」。
- 根因：上一版对「轨迹放不下整条龙」的节做 `Mathf.Lerp(backwardIndex, lastIndex, i/(n-1))` 压缩。`markerList` 越退越短（每退 5 身位 = 吃掉 250 个 marker = 5 单位轨迹），退几次后 `lastIndex - backwardIndex` 只剩个位数，所有节被压进零点几个单位里 → 必然重叠。
- 新做法（`ChainController.PushDragonBack`）：
  - 每节按 `ownIndex = i*stepMarkers - 1`（与 `DragonMovement` 跟随规则一致）算目标 `backwardIndex + ownIndex`；
  - `ownIndex > lastIndex` 的节（还没走上轨迹、仍在出生点上方排列）**直接跳过**，不再被硬拉到轨迹末端；
  - 目标点超出轨迹末端时用 `GetTrailPoint` 沿轨迹起点方向**直线延伸**（间距 = 实测 marker 间距），最多延伸 backwardIndex（≤5 单位），保证节距恒定、绝不重叠；
  - 位移改用 `DOPath(..., PathType.Linear, PathMode.TopDown2D)` 沿轨迹采样点滑行（`BuildTrailPath`，采样步长 stepMarkers/4），避免弯道直线插值互相穿插。
- 关键数据：关卡 prefab `segmentDistance: 50`、`moveSpeed: 1` → 1 个 marker = 0.02 单位，50 marker = 1 身位；C3/1 路径总长 37.5 单位。

## 修复：WebGL/TTSDK 打包失败（error CS0103 Handheld）
- 报错只有一条编译错误：`SoundManager.cs(198,13): error CS0103: 名称"Handheld"不存在`。
- 原因：`UnityEngine.Handheld`（含 `Handheld.Vibrate()`）在 **WebGL 平台整个类都不存在**，编辑器/安卓下能编译，切到 WebGL 打包就 CS0103；TTSDK 打包器在 player build 阶段直接 `Build Failed`。
- 处理：`SoundManager.TriggerVibration()` 内改用 `#if UNITY_ANDROID || UNITY_IOS` 包裹 `Handheld.Vibrate()`；WebGL/小游戏端振动走 `VibrationHelper`(NiceVibrations/TTSDK)，不要用 Handheld。
- 顺带清掉 `ChainController.DragonMovement` 里没用到的 `float minStep = 0.01f;`（CS0219 警告）。
- 经验：切 WebGL/小游戏前先全局搜 `Handheld`、`AndroidJavaObject`、`UnityEngine.iOS`、`Microphone`，这些是常见的「编辑器能跑、WebGL 编译不过」API。
